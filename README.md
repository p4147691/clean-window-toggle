# Clean Window Toggle

**작은 Chrome 창 안에서 즐기는 풀스크린.**

주소창, 탭바, 북마크바를 숨긴 Clean Window로 활성 탭을 전환하고, 영상이나 웹페이지를 현재 창 크기 안에서 집중해서 볼 수 있습니다. 모니터 전체를 차지하지 않으므로 다른 창과 나란히 배치하기 좋습니다.

## 주요 기능

- `Alt+C` 한 번: 활성 탭을 UI 없는 Clean Window로 전환
- `Alt+C` 두 번: 현재 작은 창 내부를 채우는 풀스크린 모드
- `Alt+C` 세 번: 원래 Chrome 창과 탭 구성으로 복귀
- 원래 탭, 고정 상태, 탭 그룹과 창 위치 복원
- 탭이 하나뿐인 창에서도 임시 Anchor 탭으로 원래 Chrome 창 자체를 살려 두어 복귀 안정성 향상
- Anchor는 Chrome의 평범한 새 탭 화면으로 만들며, 사용자가 그 탭에서 검색/탐색을 시작하면 자동으로 일반 사용자 탭으로 승격해 보존
- 원본 창에 탭 추가·닫기·이동, popup 탭 수동 합치기 같은 조작이 있어도 Anchor만 안전하게 정리하고 사용자 탭은 유지
- popup을 실제로 옮겼을 때만 복귀 좌표를 갱신하고, Chrome 전체화면 전환도 안전하게 이어서 처리
- 숨겨진 탭의 미디어만 일시정지하고 실제 탭은 안전하게 보존
- 자동 숨김 탭 전환기로 Clean Window 안에서도 다른 탭 선택

> 이 확장 프로그램의 풀스크린은 모니터 전체화면이 아니라 현재 Chrome 창 내부를 채우는 방식입니다.

## 설치

1. 이 저장소를 내려받거나 Releases의 ZIP을 압축 해제합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 개발자 모드를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 폴더를 선택합니다.

## 사용 권한

- `tabs`: 탭을 Clean Window로 이동하고 원래 순서와 활성 상태를 복원합니다.
- `storage`: 복원에 필요한 창·탭 상태를 사용자 기기에만 임시 저장합니다.
- `scripting`: 작은 창 내부 풀스크린 UI를 현재 탭에 적용합니다.
- `tabGroups`: 기존 탭 그룹 정보를 보존하고 복원합니다.
- `http://*/*`, `https://*/*`: 사용자가 요청한 웹페이지에서 Clean Window UI와 단축키 보조 처리를 제공합니다.

데이터를 외부 서버로 전송하거나 광고·분석·원격 코드를 사용하지 않습니다. 자세한 내용은 [개인정보 처리방침](PRIVACY.md)을 참고하세요.

## 제한 사항

- `chrome://` 등 Chrome 내부 페이지에는 콘텐츠 스크립트를 적용할 수 없어 일부 기능이 제한됩니다.
- Windows 제목 표시줄 숨김은 선택적 로컬 보조 프로그램이 있을 때만 동작하며, 없어도 기본 Clean Window와 창 내부 풀스크린 기능은 사용할 수 있습니다.
